<original_problem_statement>
The user requested an application to manage school absences. The initial request was in French: Fait moi une application avec laquelle je peux gérer les absences dans une école.

Over the course of the conversation, the user added the following requirements, which have been implemented:
- User roles: Teachers and Administration.
- Core features: Recording absences, viewing statistics.
- Simple class management (e.g., 6ème A, 5ème B).
- No authentication required for the MVP.
- A user-friendly interface for taking daily attendance with checkboxes.
- Ability to distinguish between morning (matin) and afternoon (après-midi) absences.
- Export functionality for attendance records to PDF and Excel.
- A summary export of all absentees across all classes for a given day.
- A polished and professional user interface.
- A way to make the application permanent and free, independent of the Emergent platform, as the user has no computer and will rely on a friend for deployment.
</original_problem_statement>

<what_currently_exists?>
A complete full-stack mobile application for managing school absences.
- **Backend (FastAPI)**: Provides CRUD APIs for students, classes, and absences. It includes complex endpoints for generating daily and summary attendance reports in both PDF and Excel formats. The absence model supports morning/afternoon granularity.
- **Frontend (Expo/React Native)**: A polished, tab-navigated application. Key screens include:
    - **Accueil (Home)**: A dashboard with statistics and a clear call-to-action.
    - **Faire l'appel (Take Attendance)**: An intuitive interface to select a date and class, then mark students absent for the morning or afternoon using checkboxes.
    - **Classes/Élèves (Classes/Students)**: Screens for managing classes and students.
    - **Historique (History)**: A log of all recorded absences.
- **Deployment Preparation**: A detailed deployment guide () and a Render configuration file () have been created to facilitate free, permanent hosting.
